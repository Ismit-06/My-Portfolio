🚀 Ismit Tripathy - Personal Portfolio

Welcome to my personal portfolio website! This project is a modern, interactive showcase of my journey as an Aspiring Engineer, Frontend Developer, and Graphic Designer.

It moves away from traditional scrolling websites, offering a unique fullscreen slide-based experience that feels more like a native app than a webpage.

🔗 Live Demo: View My Portfolio

✨ Key Features

Fullscreen Slide Navigation: Seamless transitions between sections (Home, About, Work, Portfolio, Contact) without vertical scrolling.

Interactive UI:

Glassmorphism: Modern frosted glass effects on profile elements.

Typing Effect: Dynamic text animation introducing my roles.

3D Parallax: Subtle mouse-movement interactions on the hero section.

Project Carousel: A touch-friendly swipeable slider for viewing my recent projects.

Theme Toggle: Built-in Dark and Light mode support.

Fully Responsive: Optimized for desktops, tablets, and mobile devices.

🛠️ Tech Stack

This portfolio was built using clean, lightweight, and modern web technologies:

HTML5: Semantic structure and content.

CSS3: Advanced animations, Flexbox, Grid, and CSS Variables for theming.

JavaScript (Vanilla): Logic for slide navigation, typing effects, and UI interactions.

Swiper.js: For the smooth project carousel.

FontAwesome: For vector icons and social links.

Google Fonts: Using 'Poppins' for clean typography.

🚀 How to Run Locally

Clone the repository:

git clone [https://github.com/Ismit-06/My-Portfolio.git](https://github.com/Ismit-06/My-Portfolio.git)


Navigate to the folder:

cd My-Portfolio


Open index.html in your browser to view the site.
